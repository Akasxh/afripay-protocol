How It Works
1
Sender Deposits USDC
Sender deposits stablecoins into the RemittanceVault smart contract. Fee: 0.5% (vs 8.9% traditional).
↓
2
Local Agent Claims Order
A verified agent near the recipient claims the order on-chain. Agents are reputation-scored and staked.
↓
3
Cash / M-Pesa Delivery
Agent delivers cash or mobile money (M-Pesa, Airtel Money) to the recipient. No bank account needed.
↓
4
Settlement + Rewards
Agent confirms delivery, receives USDC from vault. Sender earns AFRI loyalty tokens.

Smart Contract Architecture
RemittanceVault.sol
Core vault: holds stablecoin deposits, manages order lifecycle (Pending, Claimed, Completed), handles agent payouts.
FeeController.sol
Dynamic fee system: 0.5% base fee, volume discounts (down to 0.25%), corridor-specific pricing.
AgentRegistry.sol
Local cash-out agent onboarding with country-based discovery and on-chain reputation tracking.
AfriToken.sol
AFRI ERC-20 loyalty/governance token, 100M supply. Senders earn 10 AFRI per remittance.
